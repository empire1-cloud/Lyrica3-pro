# Tester Script

Send this to every tester. Keep it short.

## Message to tester

I’m testing Lyrica 3 Pro, a creator-owned AI music platform with IP proof and payment infrastructure.

I need honest feedback on one narrow flow.

## What to do

1. Open the app
2. Use the provided test account or create a creator account if that path is enabled
3. Generate one track or demo asset
4. Find the DNA / proof information attached to the output
5. Tell me whether the ownership/proof part makes sense
6. If a payment or billing status screen is shown, tell me whether it feels trustworthy or confusing

## What I want feedback on

- What confused you first?
- Did the generation flow feel clear?
- Did the proof / DNA concept make sense?
- Did anything feel fake, broken, or unfinished?
- Would you use this again?

## What not to worry about

You do not need to understand the full architecture.

I only want feedback on whether one creator flow feels real and understandable.
