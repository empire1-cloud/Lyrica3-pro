# Evidence Checklist

Capture these artifacts in one folder after every stable demo run.

## Required screenshots

- app landing or app entry
- successful login or test account entry
- `/health` response
- generation form before submit
- generation result after submit
- visible DNA tag
- visible proof metadata or API response with `dna_tag` / `track_hash`
- billing status or explicit disabled-billing state
- any ledger-visible event or proof-related view

## Required recordings

- 30 to 90 second screen recording of the full loop

## Required notes

- date and time of run
- environment used
- account used
- generation prompt or settings used
- result quality
- any failure or weirdness observed

## Minimum proof bundle

By the end of the weekend you should have:

- one working demo video
- one health screenshot
- one generation screenshot
- one proof screenshot
- one billing/ledger screenshot
- one tester feedback summary
